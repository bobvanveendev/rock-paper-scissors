# Rock Paper Scissors

A browser-based Rock Paper Scissors game with a responsive, Game Boy-inspired user interface.

[Play the live game](https://bobvanveendev.github.io/rock-paper-scissors/)

## About

This project was created as part of The Odin Project Foundations course.
The original console-based game was expanded with an interactive user interface.

Players compete against the computer. The first player to reach five points wins the game.

## Features

- Random computer choices
- Score tracking
- First-to-five win condition
- Round and game result messages
- Start and reset controls
- Responsive layout for desktop and mobile
- Game Boy-inspired design

## Built With

- HTML
- CSS
- JavaScript
- Font Awesome

## What I Learned

During this project, I practiced:

- Selecting and updating DOM elements
- Handling button click events
- Managing game state
- Separating game logic from interface updates
- Using CSS Flexbox
- Creating responsive layouts with media queries

## Run Locally

1. Clone the repository:

   ```bash
   git clone git@github.com:bobvanveendev/rock-paper-scissors.git

   ```

2. Open the project folder:

   cd rock-paper-scissors

3. Open index.html in your browser.
